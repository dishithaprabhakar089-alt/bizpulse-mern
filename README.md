# 🏪 BizPulse - Small Business Management System (MERN Stack)

A clean, modern, and organized **MERN Stack** (MongoDB, Express, React, Node.js) web application designed for retail shops, grocery stores, cafes, and small businesses to track daily cashflows, sales, expenses, and automated real-time **Net Profit / Loss**.

---

## 🌟 Teacher-Ready, Organized Interface

The interface has been completely organized into **4 focused tabs** to eliminate visual clutter and ensure effortless comprehension:

1. **📊 Dashboard (Overview)**:
   - **3 Side-by-Side Core Cards**:
     - 🟢 **Total Sales (Money In)**: Cash, UPI (GPay / PhonePe / Paytm), and Card sales.
     - 🔴 **Total Expenses (Money Out)**: Stock restock, Shop Rent, Electricity Bills, and Staff Salaries.
     - ⭐ **Net Profit / Loss**: Automatically calculates `Sales - Expenses`.
       - **Turns Green** with celebration badge when in **Profit** (`Sales > Expenses`).
       - **Turns Red** with alert badge when in **Loss** (`Expenses > Sales`).
   - **Recent Activity**: Quick snapshot of the last 5 transactions with 1-click receipt slips.
   - **Cashflow Breakdown**: Instant overview of payment modes and expense category distribution.

2. **📜 Transactions Ledger**:
   - Full searchable and filterable ledger (All, Sales only, Expenses only).
   - Instant receipt / voucher preview and printing.

3. **📈 Insights & Charts**:
   - 7-Day Revenue & Expense Flow comparison bar chart.
   - Comprehensive payment method and expense category analytics.

4. **🧭 MongoDB Compass**:
   - Step-by-step academic guide with 1-click copy for the connection URI (`mongodb://localhost:27017`).
   - Detailed schema documentation for `sales`, `expenses`, and `users` collections.
